# DDALAB Homebrew tap

```sh
brew install sdraeger/tap/ddalab
```

`ddalab` is the command line of [DDALAB](https://github.com/sdraeger/DDALAB), delay differential analysis of EEG, iEEG
and other multichannel recordings. The formula comes from each DDALAB release (cargo-dist builds it); a workflow here
copies the latest one every hour.
